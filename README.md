# Light Lights

コンソールで遊ぶローグライト風テキストRPGです。

## 仕様

- 主人公の基本パラメータは `HP`, `攻撃力`, `防御力`
- 探索中に敵と戦い、欠片を集める
- 探索終了後、欠片を使って恒久強化できる
- 1プレイごとに状況が変わるローグライト構成

## 実行方法

```bash
python main.py
```

## 操作

- `1`: 探索に出る
- `2`: 恒久強化の確認
- `3`: 終了
- 戦闘中 `a`: 攻撃
- 戦闘中 `h`: 回復薬を使う

## 今の実装内容

- 階層制の探索
- ステータス欄に踏破済み / 現在 / 先の階層が分かる階層ダイアグラムを表示
- ランダム敵とのターン制戦闘
- 戦闘中に逃走可能。逃げると欠片または所持金の一部を失う
- 敵から欠片と所持金を獲得
- 戦闘で欠片を得るたびに恒久強化を選択可能
- 無料のボーナスイベントで回復または所持金を獲得
- 所持金を支払うイベント
- 低リスク / 中リスク / 高リスクで成功率と報酬量が変わるイベント
- 死亡時に現在のステータスをリセット

## コード構成

- [main.py](main.py): 起動とメインメニュー
- [battle.py](battle.py): 敵生成と戦闘処理
- [events.py](events.py): Event クラス群とイベント発火
