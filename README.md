# Light Lights

コンソールで遊ぶローグライト風テキストRPGです。

Inscryption のローグライトパートや Arknights のローグライトに影響を受けた、リスクと選択を重視するゲームです。

## 仕様

- 主人公の基本パラメータは `HP`, `攻撃力`, `防御力`
- 探索中に敵と戦い、欠片を集める
- 探索終了後、欠片を使って恒久強化できる
- 1プレイごとに状況が変わるローグライト構成
- イベントや戦闘の分岐で、リスクと選択の積み重ねが結果に影響する

## 実行方法

```bash
python main.py
```

## 操作

- `1`: 探索に出る
- `2`: 恒久強化の確認
- `3`: 終了
- 戦闘中 `a`: 攻撃
- 戦闘中 `h`: 回復薬を使う

## 今の実装内容

- 灯路「薄明の回廊」を 8 区画進む探索
- ステータス欄に踏破済み / 現在 / 先の区画が分かる分岐ダイアグラムを表示し、次の進路を選択可能
- ランダム敵とのターン制戦闘
- 素早さは逃走成功率だけでなく、戦闘中の先手後手と回避率にも影響する
- 戦闘中に、敵との素早さ差で変動する確率で逃走可能。成功すると欠片または所持金の一部を失い、失敗すると敵の反撃を受ける
- 敵から欠片と所持金を獲得
- 戦闘で欠片を得るたびに HP / 攻撃力 / 防御力 / 素早さ の恒久強化を選択可能
- 無料のボーナスイベントで回復または所持金を獲得
- 所持金を支払うイベントで、回復薬 / 攻撃力 / 防御力 / 素早さ / 回復 の報酬を狙える
- 低リスク / 中リスク / 高リスクで成功率と報酬量が変わるイベント
- 死亡時に到達区画を表示し、恒久強化を含むステータスをリセット
