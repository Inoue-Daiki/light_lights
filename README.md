# Light Lights

コンソールで遊ぶローグライト風テキストRPGです。

Inscryption のローグライトパートや Arknights のローグライトに影響を受けた、リスクと選択を重視するゲームです。

## 仕様

- 主人公の基本パラメータは `HP`, `攻撃力`, `防御力`
- 探索中に敵と戦い、欠片を集める
- 探索終了後、欠片を使って恒久強化できる
- 1プレイごとに状況が変わるローグライト構成
- イベントや戦闘の分岐で、リスクと選択の積み重ねが結果に影響する

## 実行方法

```bash
python main.py
```

## 操作

- `1`: 探索に出る
- `2`: 恒久強化の確認
- `3`: 終了
- 戦闘中 `a`: 攻撃
- 戦闘中 `h`: 回復薬を使う

## 今の実装内容

- 灯路「薄明の回廊」を 8 区画進む探索
- ステータス欄に踏破済み / 現在 / 先の区画が分かる分岐ダイアグラムを表示し、次の進路を選択可能
- ランダム敵とのターン制戦闘
- 素早さは逃走成功率だけでなく、戦闘中の先手後手と回避率にも影響する
- 戦闘中に、敵との素早さ差で変動する確率で逃走可能。成功すると欠片または所持金の一部を失い、失敗すると敵の反撃を受ける
- 敵から欠片と所持金を獲得
- 戦闘で欠片を得るたびに HP / 攻撃力 / 防御力 / 素早さ の恒久強化を選択可能
- 無料のボーナスイベントで回復または所持金を獲得
- 所持金を支払うイベントで、回復薬 / 攻撃力 / 防御力 / 素早さ / 回復 の報酬を狙える
- 低リスク / 中リスク / 高リスクで成功率と報酬量が変わるイベント
- 死亡時に到達区画を表示し、恒久強化を含むステータスをリセット

### AI 操作用 JSON API

サーバーは 127.0.0.1:8765 にバインドする単一セッション・メモリ内ゲームです。インターネット公開用ではありません。

- GET /state: 状態、マップ、行動候補、revision
- GET /actions: 行動候補
- GET /history: 現在のランの行動履歴
- POST /action: {"action":"go:1-0","revision":1} （revision と action は直前の状態から取得）
- POST /new: {"seed":42,"revision":123} （終了したランのみ。seed は省略可能、revision は最新値）

POST は Content-Type: application/json 必須。無効な行動や古い revision は 400 を返します。人間と AI は同じ API とルールを使用します。ChatGPT から直接呼ぶための公開 MCP 接続は別途必要です。

### データの追加

- content/enemies.json: 敵名と基礎能力値（旧版と共通）
- content/events.json: 無料／有料イベント（旧版と共通）と新版の選択式イベント
- content/items.json: 新版の回復薬とレリック定義

### ベースライン比較・テスト

```bash
python agents.py --runs 50 --seed 42
python -m unittest discover -s tests -v
```

4種類のルールベース方策が同じシード集合で攻略します。LLM の接続やゲームバランスの調整は今後の課題です。マップは同一 seed で再現されますが、選択が異なると戦闘中の乱数消費は異なります。
